# Breatheline

Мобильное веб-приложение в минималистичном стиле для визуализации прожитого времени и биологических ритмов.

## Что реализовано (MVP)

- Экран профиля: дата рождения, пол, пульс, дыхание, страна.
- **Life Dashboard**: дни, часы, live-счётчик, удары сердца, вдохи, процент жизни, life line.
- **Lifetime Progress**: средняя продолжительность жизни по стране, сценарии 80/90/100, кольцевой прогресс и годы до сценария.
- **Biological Metrics**: графики накопленных ударов сердца и вдохов, сравнение в миллионах ударов.
- Сохранение данных профиля в `localStorage`.

## Запуск

Откройте `index.html` в браузере либо запустите простой сервер:

```bash
python3 -m http.server 4173
```

Затем откройте `http://localhost:4173`.
